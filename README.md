# AirControl — 用 iPhone 控制 Mac 的免费无线鼠标与触控板

AirControl 是一个免费、无广告、无内购的开源小工具，可以把你的 iPhone 变成 Mac 电脑的无线触控板、键盘和遥控器（Remote Mouse 的开源替代方案）。

非常适合把 Mac mini / MacBook 接在电视或大显示器上，躺在沙发或床上用手机控制电脑。

---

## 主要功能

- **手机当触控板用**：
  - 单指滑动移动鼠标、单指轻点左键、双指轻点右键、双指上下滑动滚轮。
  - **三指滑动** 或 **按住底部「左键」单指滑动** 即可拖拽窗口、选中文字。
- **边移鼠标边打字**：
  - 手机上半屏始终是触控板，下半屏可以随时展开键盘、应用列表、音量控制或设置。
  - 直接调用 iPhone 原生输入法给电脑打字（支持中文拼音、语音输入、退格、回车、一键把手机剪贴板粘贴到电脑）。
- **快速切换与关闭电脑程序**：
  - 手机底部点开「程序」，直接显示 Mac 当前正在运行的软件图标，点一下就能切到前台，长按可以退出软件。
- **音量与播放控制**：
  - 在手机上直接调节 Mac 系统音量、静音、播放/暂停、切歌（刷剧听歌不用起身）。
- **远程唤醒、锁屏、休眠、关机**：
  - 支持局域网唤醒（Wake-on-LAN）：Mac 睡眠息屏时，在手机上点一下「唤醒」就能亮屏使用。
  - 手机上一键控制电脑息屏、睡眠、锁屏、重启、关机。
- **不卡顿、自动秒连**：
  - 同一局域网下打开即连，支持有线网卡与无线网卡多路直连，开了 VPN 也不会断连或掉帧。

## 怎么安装使用

### 1. 电脑端（macOS 13.0 及以上）

1. 下载仓库里的 [`dist/AirControl-macOS.zip`](dist/AirControl-macOS.zip)，解压后打开 `AirControl.app`。
2. 第一次打开时，点击顶部菜单栏里的图标，选择 **「开启辅助功能权限…」**，在系统设置里把 `AirControl` 的开关打开（允许它控制电脑鼠标和键盘）。
3. 可以在菜单栏里勾选 **「登录时打开」**，以后电脑开机就会自动在后台运行，不用每次手动开。

### 2. 手机端（iOS 16.0 及以上）

1. 下载仓库里的 [`dist/AirControl.ipa`](dist/AirControl.ipa)。
2. 用你平时常用的自签工具安装到 iPhone 即可（如 SideStore、AltStore、TrollStore、Sideloadly 或爱思助手）。
3. 保证手机和 Mac 连在同一个路由器下（Mac 插网线、手机连 Wi-Fi 也可以），打开手机 App 就会自动连上电脑。

## 自己编译代码

如果你想自己从源码打包，只需在安装了 Xcode 的 Mac 上运行：

```bash
# 编译 Mac 端应用（生成到 dist/AirControl.app）
./scripts/build-macos.sh

# 编译 iPhone 端安装包（生成到 dist/AirControl.ipa）
./scripts/build-ipa.sh
```

## 常见问题

1. **鼠标移不动、点击没反应？**
   - 请去 Mac 的 `系统设置 -> 隐私与安全性 -> 辅助功能`，确认里面已经勾选了 `AirControl`。如果更新过软件版本，把它删掉重新加一次即可。
2. **电脑休眠后怎么用手机唤醒？**
   - 只要手机连上过一次电脑，就会自动记住电脑的物理地址（MAC 地址）。电脑睡眠后，打开手机 App 点「设置 -> 唤醒」即可唤醒电脑。
3. **遇到连接或卡顿问题怎么排查？**
   - 手机端「设置」里自带 **「日志导出」** 按钮，点进去可以一键复制手机和电脑两端的运行日志。
